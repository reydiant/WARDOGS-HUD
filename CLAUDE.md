# WARDOGS HUD

Single-file HTML HUD for WARDOGS (latest: `wardogs-hud-v51.html`). See README.md.

## YouTube Shorts: required every time

Before planning, cutting, titling or reviewing any WARDOGS Short:

1. Read `SHORTS-RULES.md` and follow it. It overrides the shorts-hook-title-pack and shorts-review-gates-qc skills where they disagree.
2. Read `shorts-log.csv`, fill in any new stats the user gives, and pick the next angle and the one thing to test from the Rule 5 table.
3. Hard limit: **40 seconds**, in the one-life-story format (Rule 1). No intro card. End on the 1.5 s end card. Money is never the story. Build it with `shorts-toolkit/lesson06-one-life-story` (branch `shorts-homework`).
4. After making a Short, add its row to `shorts-log.csv`, and update `SHORTS-RULES.md` (with a changelog line) whenever the stats prove a rule wrong.
